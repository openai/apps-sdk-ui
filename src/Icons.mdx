### Usage

```jsx
import { IconName } from "@openai/apps-sdk-ui/components/Icon"
```

Icons can also be imported individually through the `icons` subpath. Each icon is a standalone module with a default export, so tools like Vite and Vitest resolve only the icons you use instead of the full collection:

```jsx
import IconName from "@openai/apps-sdk-ui/icons/IconName"
```

The one exception is the `Object` icon, whose module is named `ObjectIcon`, so import it from `@openai/apps-sdk-ui/icons/ObjectIcon`.
